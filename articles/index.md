- [SNF

- [Distance

### Additional functionality

- [Stability
  Measures](https://branchlab.github.io/metasnf/articles/stability_measures.md):

  Evaluating robustness of cluster solutions through resampling methods.

- [Quality
  Measures](https://branchlab.github.io/metasnf/articles/quality_measures.md):

  Calculate context-agnostic measures of clustering compactness and
  separation.

- [Confounders](https://branchlab.github.io/metasnf/articles/confounders.md):

  Linearly regress out unwanted signal from features for clustering.

- [Parallel
  Processing](https://branchlab.github.io/metasnf/articles/parallel_processing.md):

  Leverage parallel processing to speed up the `metasnf` pipeline.

- [Label
  Propagation](https://branchlab.github.io/metasnf/articles/label_propagation.md):

  Validate or extend cluster insights to new observations through
  semi-supervised label propagation.

- [Imputations](https://branchlab.github.io/metasnf/articles/imputations.md):

  Incorporate imputation approach as another source of variability in
  the generated space of cluster solutions.

- [NMI
  Scores](https://branchlab.github.io/metasnf/articles/nmi_scores.md):

  Calculate how important various features were to the final SNF cluster
  solution.

### Plotting

- [Correlation
  Plots](https://branchlab.github.io/metasnf/articles/correlation_plots.md):

  Visualize correlations between data prior to clustering.

- [Similarity
  Matrices](https://branchlab.github.io/metasnf/articles/similarity_matrix_heatmap.md):

  Visualize the affinity matrices produced by SNF and how they associate
  with other data attributes.

- [Manhattan
  Plots](https://branchlab.github.io/metasnf/articles/manhattan_plots.md):

  Visualize a summary of the association between cluster-feature and
  feature-feature relationships.

- [Feature
  Plots](https://branchlab.github.io/metasnf/articles/feature_plots.md):

  Visualize how features are distributed within a cluster solution.

- [Alluvial
  Plots](https://branchlab.github.io/metasnf/articles/alluvial_plots.md):

  Visualize how cluster number influences the distribution of
  observations.
