# Mock example of a `t_solutions_df` metasnf object

Mock example of a `t_solutions_df` metasnf object

## Usage

``` r
mock_t_solutions_df
```

## Format

### `mock_t_solutions_df`

A transposed solutions data frame containing 20 cluster solutions
generated from `mock_solutions_df`. Used as an example of a
`t_solutions_df` metasnf object.

## Source

This data comes from the metasnf package.
