# Coerce a `t_ext_solutions_df` class object into a `data.frame` class object

Coerce a `t_ext_solutions_df` class object into a `data.frame` class
object

## Usage

``` r
# S3 method for class 't_ext_solutions_df'
as.data.frame(x, ...)
```

## Arguments

- x:

  A `t_ext_solutions_df` class object.

- ...:

  Additional parameter passed to
  [`as.data.frame()`](https://rdrr.io/r/base/as.data.frame.html).

## Value

A `data.frame` class object with all the columns of x and its contained
solutions data frame.
