# Validator for `solutions_df` class object

Validator for `solutions_df` class object

## Usage

``` r
validate_solutions_df(sol_dfl)
```

## Arguments

- sol_dfl:

  A solutions data frame-like object to be validated and converted into
  a solutions data frame.

## Value

If sol_dfl has a valid structure for a `solutions_df` class object,
returns the input unchanged. Otherwise, raises an error.
