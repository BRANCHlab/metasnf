# Convert an object to a similarity matrix list

This function converts non-`sim_mats_list` class objects into
`sim_mats_list` class objects.

## Usage

``` r
as_sim_mats_list(x)
```

## Arguments

- x:

  The object to convert into a `sim_mats_list`. Must be a list of square
  matrices with identical column and row names.

## Value

A `sim_mats_list` class object.
