# Check if max K exceeds the number of observations

Check if max K exceeds the number of observations

## Usage

``` r
check_valid_k(sdf, dl)
```

## Arguments

- sdf:

  A `settings_df` class object.

- dl:

  A nested list of input data from
  [`data_list()`](https://branchlab.github.io/metasnf/reference/data_list.md).

## Value

Doesn't return any value. Raises error if max K exceeds the number of
observations.
