# Validator for `ari_matrix` class object

Validator for `ari_matrix` class object

## Usage

``` r
validate_ari_matrix(aml)
```

## Arguments

- aml:

  An ari_matrix-like matrix object to be validated.

## Value

If aml has a valid structure for a `ari_matrix` class object, returns
the input unchanged. Otherwise, raises an error.
