# Mock example of a `clust_fns_list` metasnf object

Mock example of a `clust_fns_list` metasnf object

## Usage

``` r
mock_clust_fns_list
```

## Format

### `mock_clust_fns_list`

A `clust_fns_list` object containing two clustering functions covering 2
and 5 five cluster solution versions of spectral clustering. Extracted
from `mock_snf_config`.

## Source

This data comes from the metasnf package.
