# Mock example of a `solutions_df` metasnf object

Mock example of a `solutions_df` metasnf object

## Usage

``` r
mock_solutions_df
```

## Format

### `mock_solutions_df`

A solutions data frame containing 20 cluster solutions generated from
`mock_snf_config` and `mock_data_list`. Used as an example of an
`solutions_df` metasnf object.

## Source

This data comes from the metasnf package.
