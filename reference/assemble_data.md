# Collapse a data frame and/or a data list into a single data frame

Collapse a data frame and/or a data list into a single data frame

## Usage

``` r
assemble_data(data, dl)
```

## Arguments

- data:

  A data frame.

- dl:

  A nested list of input data from
  [`data_list()`](https://branchlab.github.io/metasnf/reference/data_list.md).

## Value

A class "data.frame" object containing all the features of the provided
data frame and/or data list.
