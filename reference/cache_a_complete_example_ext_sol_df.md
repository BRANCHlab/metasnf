# Cached example extended solutions data frame

An extended solutions data frame used as a cached example in the
"a_complete_example.Rmd" vignette.

## Usage

``` r
cache_a_complete_example_ext_sol_df
```

## Format

### `cache_a_complete_example_ext_sol_df`

Contains 20 cluster solutions, 87 observations, and p-values for 336
features.

## Source

This data came from the metasnf package.
