# Summarize p-value columns of an extended solutions data frame

Summarize p-value columns of an extended solutions data frame

## Usage

``` r
summarize_pvals(ext_sol_df)
```

## Arguments

- ext_sol_df:

  Result of `extend_solutions`

## Value

The provided extended solutions data frame along with columns for the
min, mean, and maximum across p-values for each row.
