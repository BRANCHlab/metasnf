# Reorder the uids in a data list

Reorder the uids in a data list

## Usage

``` r
reorder_dl_uids(dl, ordered_uids)
```

## Arguments

- dl:

  A nested list of input data from
  [`data_list()`](https://branchlab.github.io/metasnf/reference/data_list.md).

- ordered_uids:

  A vector of the uid values in the data list in the desired order of
  the sorted data list.

## Value

A data list ("list"-class object) with reordered observations.
