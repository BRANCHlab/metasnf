# Check if items of a clustering functions list-like object are functions

Check if items of a clustering functions list-like object are functions

## Usage

``` r
check_cfll_fns(cfll)
```

## Arguments

- cfll:

  A clust_fns_list-like `list` class object.

## Value

Doesn't return any value. Raises error if the items of cfll are not
functions.
