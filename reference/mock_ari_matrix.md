# Mock example of an `ari_matrix` metasnf object

An `ari_matrix` class object containing adjusted Rand indices (ARIs)
between 20 cluster solutions. Used as an example of an `ari_matrix`
metasnf object.

## Usage

``` r
mock_ari_matrix
```

## Format

### `mock_ari_matrix`

A 20 by 20 ARI matrix.

## Source

This data comes from the metasnf package.
